# kof-maximum-impact-recompilation
Overview
This repository aims to explore the technical feasibility of creating a native PC recompilation of The King of Fighters: Maximum Impact, originally released for the PlayStation 2.

Goals
Research the game's engine and executable structure.
Document file formats and assets.
Investigate reverse-engineering possibilities.
Evaluate recompilation techniques.
Preserve the game for modern platforms.
Benefits
A successful recompilation could provide:

Native PC support
Higher resolutions
Widescreen support
Better performance
Modern controller compatibility
Community modding support
Status
Concept / Research Phase

Contributors
Contributions from reverse engineers, developers, modders and KOF fans are welcome.
